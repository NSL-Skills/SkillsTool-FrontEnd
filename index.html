The University of North Texas (UNT-CPNC)

Welcome to the CPNC Demo Tool

This tool enables you to view entry-level job postings, then parse and analyze those postings in real time. A set of learning outcomes is created from each posting, then compared with a pre-loaded set of outcomes directly sourced from CAE Institutions (Center for Academic Excellence).

Get started by choosing either the Example Data or Custom Data tab!

NOTE: This demo is a work in-progress.
